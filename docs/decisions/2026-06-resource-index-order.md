# 资源索引时间排序决策

## 背景

- 资源索引原先在分类内按标题升序展示，用户无法优先看到最新周报中的链接。
- 目标是在不改变分类、搜索、去重和存储结构的前提下，让最新资源排在最前。

## 决策

- 页面展示前，按资源最近一次被周报提及的周报结束日期倒序排列。
- 同一链接被多期周报提及时，以最新一次提及日期为准。
- 日期相同时按标题升序排列；无法解析日期的资源排在最后。
- 排序只作用于传给资源索引页面的数据副本，不修改持久化索引。

## 风险与回滚

- 周报标题缺少标准日期范围时，该资源会排在有日期的资源之后。
- 回滚时移除页面入口的排序调用和对应辅助函数即可，无需迁移或清理数据。
